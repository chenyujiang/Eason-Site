# Eason Site

Eason Chen's personal site — a single-page "mission control" themed portfolio built from his resume: an animated hero node-graph of his 4D model (Delegation, Description, Discernment, Diligence), a skills panel, an experience log, certifications, and contact info.

## Stack

React 19 + Vite + TypeScript, Framer Motion for animation, CSS Modules for styling, self-hosted fonts via `@fontsource` (Space Grotesk, Inter, JetBrains Mono).

## Commands

```bash
npm install
npm run dev      # local dev server
npm run build     # production build (tsc -b && vite build)
npm run lint      # eslint
npm run preview   # preview the production build
```

See `CLAUDE.md` for project structure, architecture notes, and installed Claude Code skills.
